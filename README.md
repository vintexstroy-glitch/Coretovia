# Coretovia

Книгата е Заданието. Всеки лист от една работна книга (.xlsx) е прозорец на програмата —
осем са. Един Журнал (само за добавяне, хеш-верига), една Врата, една Порта, и изкуствен
интелект, който може само каквото програмата може.

**Издание:** резен 0 · скелетът. **Наследник на** MasterBook (VintexStroy, таг
`alfa-kray-2026-09-05`) — пренесено е ядрото с тестовете му; всичко друго се строи наново ОТ
Книгата. Кое е пренесено, кое се пренаписва, кое чака и кое отпада — `docs/registar-na-prenosa.md`.

**Местно-първо.** Журналът живее в браузъра; няма сървър; нищо не тръгва навън. Единствената
чужда библиотека е ExcelJS (MIT), за да се отваря Книгата в Excel като неговата.

## Какво има тук

```
zadanie/            ЗАДАНИЕТО · Книгата, клетка по клетка, по прозорец (01–08)
src/yadro/          ядрото · Журнал · Врата · пари · сверка · такт · котва · права (пренос)
src/model/          моделът като данни · осемте прозореца (osnova.ts)
src/kniga/          Книгата · ooxml.ts (ЕДИНСТВЕНИЯТ внос на exceljs)
src/nositel/        IndexedDB · хеш · хранилище (пренос)
src/ogledalo/       сгъването на веригите (пренос) · колонното Огледало идва в резен 1
app/                екранът · vanilla TS + DOM
tests/              инвариантите · машинните пазачи · мострата (tests/mostri/)
proba/              проходът през истински браузър
stroezh/            обходите: чистота · честност · лицензи · печат на джоба · мостра
docs/               решенията (ADR) · планът · регистърът на преноса · пазарът (docs/pazar/)
```

## Пускане

```bash
npm install
npm run dev          # http://localhost:5173
npm run proverka     # всички порти
npm run proba        # проходът в Chromium
npm run mostra       # синтетичната Книга в tests/mostri/
```
